**Time:** 0–15s
**Delivery:** Calm and direct.

    A small movement can carry an important message. Reach is a free, open source communication app built with AI assistance. It turns a compatible webcam and a browser into a way to select words and have them spoken.

**Time:** 15–38s
**Delivery:** Leave space for the pointer demonstration.

Hold over a large phrase to select it. No keyboard key needs to be held. This animation illustrates the interaction; it is not a clinical test.

That is a historical hardware price, not a current quote or a complete communication system.
